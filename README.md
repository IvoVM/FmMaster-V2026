# FmMaster-V2026

Sitio nuevo de FM Master. El proyecto anterior no se modifica.

```bash
npm install
npm run dev
```

El cartel sale solo del calendario de Miramar: en 2026 dice “Más de 26 años siendo TU MEJOR COMPAÑÍA...” y en 2027, 27. La cuenta está en `src/lib/years.js`.

Si cambiás fotos en el proyecto viejo y querés regenerar las del carrusel:

```bash
npm run images
```
